# LabMatch Allocator

A ready-to-run React + Vite website for the DSA project **Automated Student–Laboratory Allocation System Using Maximum Bipartite Matching**.

## Run in VS Code

1. Open this folder in VS Code.
2. Open the terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL shown by Vite.

## Features

- Dashboard
- Student management
- Laboratory management
- Capacity-aware Maximum Bipartite Matching
- Allocation report
- Bipartite graph visualization
- Project/DSA explanation
- Add/delete students and laboratories
- Demo data reset

No database or backend is required. Data is stored in React state for the current session.
